- ❌ 下层模块依赖上层模块

- ❌ 循环依赖

## 2. 核心 API

### CheckResult（检测结果）

```python
from nastool_core.checks.base import CheckResult

result = CheckResult(
    check_id="nvidia_driver_version",   # 检测项唯一 ID
    title="NVIDIA 驱动版本",             # 显示名称
    category="ai",                       # 类别: ai/nas/network/security/storage/system
    severity="passed",                   # 严重级别: passed/warning/info/critical
    passed=True,                         # 是否通过
    message="NVIDIA driver 535.54.03",   # 简短消息
    details="...",                       # 详细信息
    current="535.54.03",                 # 当前值
    expected="535+",                     # 期望值
    fix_available=True,                  # 是否有自动修复
    fix_description="Update driver",     # 修复描述
    fix_command="apt install ...",       # 修复命令
    fix_risk="low",                      # 修复风险: low/medium/high
    url="https://...",                   # 参考链接
)
```

### CheckSeverity（严重级别）

```python
from nastool_core.checks.base import CheckSeverity

# 可用值：
CheckSeverity.PASSED     # 通过
CheckSeverity.INFO       # 信息
CheckSeverity.WARNING    # 警告
CheckSeverity.CRITICAL   # 严重

# ❌ 不要使用（旧 API，已废弃）：
# CheckSeverity.OK / CheckSeverity.ERROR
```

### CheckCategory（检测类别）

```python
from nastool_core.checks.base import CheckCategory

# 可用值：
CheckCategory.AI
CheckCategory.NAS
CheckCategory.NETWORK
CheckCategory.SECURITY
CheckCategory.STORAGE
CheckCategory.SYSTEM
```

### CheckContext（检测上下文）

```python
from nastool_core.checks.decorators import CheckContext

ctx = CheckContext(...)

# 返回结果方法：
ctx.passed(message="OK")           # 通过
ctx.failed(message="FAIL")         # 失败（CRITICAL）
ctx.skipped(message="SKIP")        # 跳过

# 组合方法：
ctx.result(passed=True, ...)       # 委托给 passed() 或 failed()
```

## 3. 新增检测项流程

### 步骤

1. 在 `nastool-core/nastool_core/checks/` 下找到对应类别目录
2. 创建检测文件，使用 `@register_check` 装饰器注册
3. 在 `nastool-core/nastool_core/data/mock_results.py` 中添加 Mock 数据
4. 编写单元测试
5. 运行验证

### 示例：添加新检测项

```python
# nastool-core/nastool_core/checks/ai/new_check.py
from nastool_core.checks.decorators import register_check, CheckContext

@register_check("ai", "new_gpu_check")
def check_gpu_temperature(ctx: CheckContext) -> CheckResult:
    """检测 GPU 温度"""
    temp = ctx.adapter.get_gpu_temp()
    if temp > 85:
        return ctx.failed(
            message=f"GPU temperature too high: {temp}C",
            current=str(temp),
            expected="<85C"
        )
    return ctx.passed(
        message=f"GPU temperature normal: {temp}C",
        current=str(temp),
        expected="<85C"
    )
```

### Mock 数据格式

在 `mock_results.py` 对应类别的字典中添加：

```python
AI_MOCK = {
    # ... 已有条目 ...
    "new_gpu_check": {
        "severity": CheckSeverity.PASSED,
        "passed": True,
        "current": "45C",
        "expected": "<85C",
        "message": "GPU temperature normal: 45C"
    },
}
```

## 4. 新增适配器流程

### 步骤

1. 在 `nastool-adapters/nastool_adapters/` 下创建适配器文件
2. 继承 `BaseAdapter` 基类
3. 实现必要方法
4. 使用 `@register_adapter` 注册
5. 编写单元测试

### 示例

```python
# nastool-adapters/nastool_adapters/my_adapter.py
from nastool_adapters.base import BaseAdapter, AdapterResult

@register_adapter("my_device")
class MyAdapter(BaseAdapter):
    def connect(self) -> AdapterResult:
        """连接设备"""
        ...

    def disconnect(self) -> AdapterResult:
        """断开连接"""
        ...

    def execute(self, command: str) -> AdapterResult:
        """执行命令"""
        ...
```
