# NASTool 用户手册

> 版本：v1.0.0 | 更新日期：2026-04-19

---

## 1. 产品简介

NASTool 是一款 ARM/NAS 设备诊断工具包，提供 90+ 项自动化检测，覆盖 AI 环境、NAS 服务、网络、安全、存储和系统六大类别。支持命令行（CLI）和图形界面（GUI）两种使用方式。

### 核心能力

| 能力 | 说明 |
|------|------|
| 90 项自动检测 | 覆盖 6 大类别，一键发现设备问题 |
| 4 种 Mock 模式 | 无设备也能体验完整诊断流程 |
| 交互式修复 | 检测问题后可一键修复 |
| 多格式报告 | 终端彩色 / JSON / 文本 / HTML |
| GUI 可视化 | 图形界面查看诊断结果 |

### 检测类别

| 类别 | 项数 | 覆盖范围 |
|------|------|---------|
| AI 环境 | 24 | NVIDIA 驱动、CUDA、TensorRT、PyTorch、ONNX、GPU 内存等 |
| NAS 服务 | 16 | SMB/NFS/FTP/SFTP/WebDAV、UPS、备份、RAID 等 |
| 网络 | 13 | 互联网、DNS、带宽、延迟、MTU、代理等 |
| 安全 | 11 | 防火墙、SSH、SSL 证书、Fail2ban、ClamAV 等 |
| 存储 | 11 | 磁盘空间、SMART、RAID、ZFS、IO 等待等 |
| 系统 | 15 | Python、Docker、内存、CPU 温度、内核版本等 |

## 2. 安装指南

### 方式一：pip 安装（推荐）

```bash
# 解压交付包
unzip nastool-v1.0.0.zip
cd nastool-v1.0.0

# 按顺序安装各模块
pip install nastool-common/
pip install nastool-core/
pip install nastool-adapters/
pip install nastool-reporters/
pip install nastool-fixes/
pip install nastool-cli/

# 验证安装
nastool --version
```

### 方式二：开发模式安装

```bash
cd nastool-v1.0.0

pip install -e nastool-common/
pip install -e nastool-core/
pip install -e nastool-adapters/
pip install -e nastool-reporters/
pip install -e nastool-fixes/
pip install -e nastool-cli/
```

### 卸载

```bash
pip uninstall nastool-cli nastool-fixes nastool-reporters nastool-adapters nastool-core nastool-common -y
```

## 3. 快速开始（5 分钟上手）

### 第一次诊断

```bash
# 快速诊断（89 项，约 5 秒）
nastool

# 完整诊断（93 项，含基准测试）
nastool --full
```

### 使用 Mock 数据体验

无需真实设备，直接体验完整诊断流程：

```bash
nastool --mock healthy    # 健康设备（96 分）
nastool --mock degraded   # 降级设备（87 分）
nastool --mock critical   # 严重故障（58 分）
nastool --mock mixed      # 混合场景（70 分）
```

### 保存报告

```bash
# JSON 格式
nastool --output report.json --json

# 文本格式
nastool --output report.txt

# 仅终端显示 JSON
nastool --json
```

## 4. 命令行参考

### 完整参数

```
nastool [选项]

选项：
  -h, --help            显示帮助信息
  --version             显示版本号
  --full                完整诊断（含基准测试，93 项）
  --fix                 诊断 + 交互式修复
  --fix-auto            诊断 + 自动修复（无需确认）
  --list-fixes          列出所有可用修复项
  --mock PROFILE        使用 Mock 数据（healthy/degraded/critical/mixed）
  --output FILE, -o FILE  报告输出文件
  --json                JSON 格式输出
  --no-color            禁用彩色输出
  --category CAT        仅运行指定类别的检测
```

### 常用命令示例

| 命令 | 说明 |
|------|------|
| `nastool` | 快速诊断（默认 89 项） |
| `nastool --full` | 完整诊断（93 项，含基准测试） |
| `nastool --mock healthy` | Mock 模式体验 |
| `nastool --fix` | 诊断后交互式修复 |
| `nastool --fix-auto` | 自动修复（谨慎使用） |
| `nastool --list-fixes` | 查看可用修复项 |
| `nastool -o report.json --json` | 保存 JSON 报告 |
| `nastool -o report.txt` | 保存文本报告 |
| `nastool --no-color` | 无颜色输出（适合重定向） |
| `nastool --json` | 终端直接输出 JSON |

## 7. 报告解读

### 评分含义

| 分数范围 | 等级 | 含义 |
|---------|------|------|
| 90-100 | A | 设备健康，所有关键项通过 |
| 70-89 | B | 基本正常，有少量警告需关注 |
| 50-69 | C | 存在问题，建议尽快修复 |
| 0-49 | D | 严重故障，需立即处理 |

### 严重级别

| 级别 | 含义 |
|------|------|
| PASSED | 检测通过，无需操作 |
| INFO | 信息性提示，不影响功能 |
| WARNING | 警告，建议关注 |
| CRITICAL | 严重问题，需立即修复 |

## 8. 常见问题 FAQ

### Q: 安装后 `nastool` 命令不可用？
A: 确认 pip 安装顺序正确（common → core → adapters → reporters → fixes → cli），检查 Python Scripts 目录是否在 PATH 中。

### Q: Windows 终端显示乱码？
A: NASTool v1.0.0 已自动处理 Windows GBK 编码问题。如仍有乱码，尝试 `chcp 65001` 切换到 UTF-8 代码页。

### Q: 没有真实设备，如何体验？
A: 使用 `--mock` 参数，4 种 Mock 配置可模拟不同设备状态。

### Q: `--fix` 修复是否安全？
A: 所有高危修复操作前都会二次确认。`--fix` 模式需手动确认，`--fix-auto` 会自动执行（谨慎使用）。

### Q: 支持哪些操作系统？
A: CLI 和核心功能跨平台（Windows/Linux/macOS）。GUI 基于 tkinter，同样跨平台。
