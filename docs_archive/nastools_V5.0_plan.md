# nastools v5.0 规划

> 版本：v5.0
> 主题：**可用版本** — 连接只是手段，检测才是目的
> 目标：**免费、傻瓜、覆盖广、检测齐全的 ARM NAS 诊断工具**

---

## 一、已实现功能（v4.2.0）

| 类别 | 数量 | 说明 |
|------|------|------|
| **检测项** | 35 | 系统8/网络6/存储8/AI2/安全5/NAS6 |
| **修复项** | 16+ | 系统4/网络1/存储5/安全4/AI1/NAS1 |
| **适配器** | 11 | 群晖/威联通/Jetson/RK/寒武纪/ADB/通用 |
| **连接方式** | 5 | SSH/USB/ADB/USB Gadget/Relay |
| **报告器** | 7 | HTML/JSON/终端/友好/仪表盘 |
| **GUI** | 7 | 主界面/USB/Relay/备份/回滚/卸载/历史 |

## 二、核心认知

```
连接 = 手段（让检测能跑）
检测 = 目的（知道 NAS 健不健康）
```

**重点：检测功能必须能用、必须准确、结果必须易懂**
