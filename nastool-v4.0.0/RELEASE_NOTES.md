## 1. 新功能

### 1.1 多源数据验证系统

- **数据源扩展**: 支持thermal_zone、sensors、hwmon、vcgencmd等多种数据源
- **数据融合**: 支持8种融合方法（加权平均、中位数、均值、众数、几何平均、调和平均、最小值、最大值）
- **异常值检测**: 支持Z-score、IQR、MAD三种检测算法
- **一致性验证**: 检查数据的时间、值、趋势和源一致性
- **置信度评分**: 综合评估检测结果的可靠性

### 1.2 自适应阈值系统

- **设备识别**: 自动识别RK3588、Jetson等多种ARM设备
- **专用阈值**: 为不同设备类型配置专用的温度和性能阈值
- **动态调整**: 根据环境因素动态调整阈值

### 1.3 校准机制

- **校准因子**: 支持设备特定的校准因子
- **标准工具比对**: 与lm-sensors、ipmitool等标准工具比对
- **校准流程**: 提供完整的校准指南

### 1.4 环境感知系统

- **环境数据采集**: 记录检测时的CPU负载、内存使用等环境数据
- **条件检测**: 在特定条件下进行检测，提高结果可靠性
- **环境标记**: 将环境数据与检测结果关联

### 1.5 历史数据分析

- **历史存储**: 支持30天历史数据存储
- **趋势分析**: 分析设备状态的长期趋势
- **历史对比**: 比较不同时间点的检测结果
- **趋势图表**: 直观展示设备状态变化

## 2. 改进

### 2.1 性能优化

- **数据融合优化**: 优化了异常值检测和融合算法，提高执行效率
- **缓存机制**: 实现智能缓存，减少重复检测
- **并行处理**: 支持并行检测多个目标
- **资源使用**: 减少内存和CPU使用

### 2.2 检测准确性

- **多源验证**: 通过多个数据源验证检测结果
- **异常值过滤**: 自动识别和过滤异常数据
- **一致性检查**: 确保数据的时间和值一致性
- **置信度评估**: 提供量化的置信度指标

### 2.3 用户体验

- **详细报告**: 生成更加详细和直观的检测报告
- **趋势分析**: 提供设备状态的长期趋势分析
- **配置简化**: 简化配置流程，支持自动设备识别
- **错误处理**: 增强错误处理和降级机制

### 2.4 系统集成

- **API扩展**: 提供更加丰富的Python API
- **命令行增强**: 支持更多命令行参数和选项
- **批量处理**: 支持批量设备检测和管理
- **监控集成**: 支持与监控系统集成

## 4. 升级指南

### 4.1 从V4.0升级

```bash
# 停止旧版本
sudo systemctl stop nastool

# 备份配置
cp ~/.nastool/config.json ~/.nastool/config.json.bak

# 更新代码
git pull

# 安装新依赖
pip install -r requirements.txt

# 运行升级脚本
python scripts/upgrade.py

# 启动服务
sudo systemctl start nastool
```

### 4.2 配置迁移

V4.1版本引入了新的配置格式，升级脚本会自动迁移旧配置。主要变更：

- **阈值配置**: 新增设备特定阈值
- **数据融合**: 新增融合方法配置
- **历史存储**: 新增历史数据配置

### 4.3 验证升级

```bash
# 运行自检
nastool --self-test

# 验证版本
nastool --version

# 执行测试检测
nastool --target localhost
```

## 6. 已知问题

### 6.1 限制

- **环境温度检测**: 仅在部分设备上支持环境温度检测
- **GPU检测**: 部分老旧GPU可能无法识别
- **历史存储**: 长时间运行后可能需要清理历史数据
- **网络检测**: 在高延迟网络环境下可能超时

### 6.2 解决方法

- **环境温度**: 如无环境温度传感器，将使用CPU温度作为参考
- **GPU识别**: 对于无法识别的GPU，使用通用检测方法
- **历史数据**: 定期运行 `nastool --clean-history` 清理旧数据
- **网络超时**: 调整网络检测超时设置 `--timeout 10`
