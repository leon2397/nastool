## 新电脑使用指南

### 1. 直接运行（无需安装）

```powershell
cd D:\project\nastool7\deploy
.\nastool-launcher.exe   # 窗口化启动
# 或
.\nastool.exe --version  # 命令行
```

### 2. 开发环境重建

```powershell
# 创建虚拟环境
cd D:\project\nastool7\nastool-v4.0.0
python -m venv venv
.\venv\Scripts\activate

# 安装依赖（可编辑模式）
pip install -e ./nastool-common
pip install -e ./nastool-core
pip install -e ./nastool-adapters
pip install -e ./nastool-reporters
pip install -e ./nastool-fixes
pip install -e ./nastool-cli

# 验证安装
nastool --version
nastool --mock healthy
```

### 3. 连接 ARM 设备

**方式一：直接 SSH（同一网络）**
```bash
ssh nvidia@192.168.1.123
# 密码：nvidia
```

**方式二：通过 Relay Server（不同网络）**
```powershell
# 确保设备已部署 Agent 并连接到 Relay
nastool --relay http://120.77.249.3:18888 --device nvidia-01
```
