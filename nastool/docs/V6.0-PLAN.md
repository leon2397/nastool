## 一、产品定位

### 1.1 核心定位

**面向嵌入式 ARM 设备的智能诊断平台**

自动识别设备型号 → 加载对应检测策略 → 输出可执行的诊断结论

### 1.2 目标用户

- NAS 玩家（QNAP / Synology / 威联通 / 群晖）
- AI 开发板用户（Jetson / Orange Pi / Rock Pi）
- 树莓派爱好者
- 边缘计算部署工程师
- DIY NAS 玩家

### 1.3 核心价值

> 让任何人在任何 ARM 设备上，无需配置，开箱即用地获得专业的设备诊断体验

## 二、现状问题分析

### 2.1 根本原因

当前版本采用「通用 Linux 服务器」的检测模型，核心假设与真实 ARM 设备脱节：

| 现有假设 | 现实 | 后果 |
|----------|------|------|
| 有 nvidia-smi | Jetson 用 tegrastats | GPU 检测失效 |
| nvcc 在 PATH | CUDA 装在 /usr/local/cuda-11.4 | CUDA 检测失效 |
| 是通用 Linux | 各厂商有专有工具链 | 检测大量失效 |
| 用户有 root | 生产环境非 root | 权限错误直接崩溃 |
| Python 3.10+ | ARM 设备普遍 3.8-3.9 | 无法运行 |
| 路径固定 | 各设备路径差异大 | 检测不准确 |

### 2.2 架构缺陷

1. **设备识别缺失**：没有设备身份识别环节，直接套用通用检测
2. **策略耦合过紧**：检测逻辑与设备特性硬编码绑定
3. **适配能力缺失**：无法按设备类型切换检测方式
4. **异常处理薄弱**：文件系统操作无权限兜底

## 四、核心模块设计

### 4.1 设备指纹识别（adapters/detector.py）

设备识别是整个架构的前置环节，决定后续使用哪个适配器。

```python
@dataclass
class DeviceInfo:
    vendor: str                           # NVIDIA / Raspberry Pi / Rockchip / ...
    model: str                            # Jetson Xavier NX / RK3588 / RPi4
    arch: str                             # aarch64 / armv7l
    os_name: str                          # Ubuntu / Raspbian / QTS
    os_version: str
    capabilities: List[str]              # 当前环境可用能力列表
    python_version: str
    is_privileged: bool                  # 是否 root

class DeviceFingerprint:
    """多维度设备指纹识别"""

    def detect(self) -> DeviceInfo:
        return DeviceInfo(
            vendor=self._detect_vendor(),
            model=self._detect_model(),
            arch=self._detect_arch(),
            os_name=self._detect_os_name(),
            os_version=self._detect_os_version(),
            capabilities=self._detect_capabilities(),
            python_version=self._detect_python_version(),
            is_privileged=self._check_privileged(),
        )

    def _detect_vendor(self) -> str:
        """识别设备厂商"""
        # 优先级：
        # 1. /sys/firmware/dev-tree/model （设备树，最权威）
        # 2. /proc/device-tree/compatible
        # 3. 厂商工具检测
        # 4. /etc/os-release
        ...

    def _detect_capabilities(self) -> List[str]:
        """
        探测当前环境有哪些检测能力可用
        这个输出决定了适配器能做什么
        """
        caps = []

        # GPU 检测能力
        if shutil.which('nvidia-smi'):
            caps.append('gpu:nvidia-smi')
        if shutil.which('tegrastats'):
            caps.append('gpu:tegrastats')
        if Path('/dev/nvhost-vic').exists():
            caps.append('gpu:jetson-hw')

        # CUDA 检测能力
        if shutil.which('nvcc'):
            caps.append('cuda:nvcc')
        for p in Path('/usr/local').glob('cuda*/bin/nvcc'):
            caps.append(f'cuda:installed:{p.parent.parent}')

        # 温度检测能力
        if Path('/sys/class/thermal').exists():
            caps.append('thermal:sysfs')
        if shutil.which('vcgencmd'):
            caps.append('thermal:vcgencmd')

        # 存储检测能力
        if shutil.which('smartctl'):
            caps.append('storage:smart')
        if shutil.which('lsblk'):
            caps.append('storage:lsblk')

        return caps
```

### 4.2 适配器基类（adapters/base.py）

适配器是架构的核心抽象，每个设备类型一个适配器。

```python
class BaseAdapter(ABC):
    """设备适配器基类——定义统一接口"""

    vendor: str
    models: List[str]

    # ---------- GPU / NPU ----------
    @abstractmethod
    def get_gpu_info(self) -> Optional[GPUInfo]:
        pass

    # ---------- CUDA / Compute ----------
    def get_cuda_info(self) -> Optional[CUDAInfo]:
        """默认实现：遍历常见路径查找 nvcc"""
        for path in sorted(Path('/usr/local').glob('cuda*'), reverse=True):
            nvcc = path / 'bin' / 'nvcc'
            if nvcc.exists():
                return CUDAInfo(version=self._parse_cuda_version(nvcc), path=str(path))
        return None

    # ---------- 温度 ----------
    @abstractmethod
    def get_thermal_info(self) -> ThermalInfo:
        pass

    # ---------- 功耗 ----------
    def get_power_info(self) -> Optional[PowerInfo]:
        """可选实现，非所有设备都有"""
        return None

    # ---------- 存储 ----------
    def get_storage_info(self) -> List[DiskInfo]:
        """使用平台统一的存储检测"""
        ...

    # ---------- 工具函数 ----------
    def check_readable(self, path: Path) -> bool:
        try:
            path.exists()
            return True
        except PermissionError:
            return False

    def safe_read(self, path: Path) -> Optional[str]:
        try:
            return path.read_text()
        except (PermissionError, FileNotFoundError, UnicodeDecodeError):
            return None
```

### 4.3 Jetson 适配器（adapters/jetson/adapter.py）

```python
class JetsonAdapter(BaseAdapter):
    """
    NVIDIA Jetson 系列适配器
    支持：Xavier NX / AGX Xavier / Nano / Orin
    """

    vendor = "NVIDIA"
    models = ["Jetson Xavier NX", "Jetson AGX Xavier", "Jetson Nano", "Jetson Orin"]

    def get_gpu_info(self) -> Optional[GPUInfo]:
        """
        Jetson 的 GPU 是 SoC 内置的，不依赖 nvidia-smi
        检测路径：tegrastats > sysfs > 设备树
        """
        model = self._read_device_model()

        if shutil.which('tegrastats'):
            return self._parse_tegrastats(model)

        # 降级：读取 sysfs GPU 节点
        gpu_nodes = list(Path('/dev').glob('nvhost-*'))
        if gpu_nodes:
            return GPUInfo(
                model=model,
                memory_total=self._read_gpu_mem_total(),
                status="active",
                source="nvhost-dev"
            )

        return None

    def get_thermal_info(self) -> ThermalInfo:
        """
        Jetson 有丰富的温度传感器
        /sys/class/thermal/thermal_zone* 下每个 zone 都是一个传感器
        """
        temps = {}
        thermal_base = Path('/sys/class/thermal')
        if not thermal_base.exists():
            return ThermalInfo(zones={})

        for zone in sorted(thermal_base.glob('thermal_zone*')):
            name_file = zone / 'type'
            temp_file = zone / 'temp'
            if name_file.exists() and temp_file.exists():
                name = self.safe_read(name_file, '').strip()
                try:
                    temp = int(self.safe_read(temp_file, '').strip()) / 1000
                    temps[name] = temp
                except (ValueError, TypeError):
                    pass

        return ThermalInfo(zones=temps)

    def get_cuda_info(self) -> Optional[CUDAInfo]:
        """
        Jetson 的 CUDA 通常装在 /usr/local/cuda-*/
        且可能不在 PATH 中
        """
        candidates = [
            Path(os.environ.get('CUDA_HOME', '')) if os.environ.get('CUDA_HOME') else None,
            *list(Path('/usr/local').glob('cuda*')),
            Path('/usr/local/cuda'),
        ]

        for path in candidates:
            if path is None:
                continue
            nvcc = path / 'bin' / 'nvcc'
            if nvcc.exists():
                version = self._parse_cuda_version(nvcc)
                return CUDAInfo(version=version, path=str(path), jetpack=self._detect_jetpack())

        return None
```

### 4.4 检测策略模式（checks/strategies.py）

策略模式让同一个检测项可以根据设备类型选择不同实现。

```python
class CheckStrategy(ABC):
    """检测策略基类"""
    check_id: str

    @abstractmethod
    def run(self, adapter: BaseAdapter, ctx: CheckContext) -> CheckResult:
        pass


class StrategyRegistry:
    """策略注册表——按设备厂商路由"""

    def __init__(self):
        self._table: Dict[str, Dict[str, Type[CheckStrategy]]] = {}

    def register(self, check_id: str, vendor: str = 'generic'):
        def decorator(cls):
            self._table.setdefault(check_id, {})[vendor] = cls
            return cls
        return decorator

    def get(self, check_id: str, vendor: str) -> CheckStrategy:
        table = self._table.get(check_id, {})
        strategy_class = table.get(vendor) or table.get('generic')
        if strategy_class is None:
            raise NotImplementedError(f"No strategy for {check_id}/{vendor}")
        return strategy_class()


# 全局注册表
registry = StrategyRegistry()
```

### 4.5 GPU 检测策略示例

```python
# checks/strategies/gpu_strategies.py

@registry.register('gpu_detected', 'generic')
class GenericGPUDetector(CheckStrategy):
    """通用 GPU 检测策略——x86 服务器"""

    def run(self, adapter: BaseAdapter, ctx: CheckContext) -> CheckResult:
        if shutil.which('nvidia-smi'):
            # NVIDIA 独立显卡
            result = subprocess.run(
                ['nvidia-smi', '--query-gpu=name,memory.total,utilization.gpu',
                 '--format=csv,noheader'],
                capture_output=True, text=True, timeout=10
            )
            if result.returncode == 0:
                name, mem, util = result.stdout.strip().split(', ')
                return CheckResult(
                    check_id='gpu_detected', passed=True,
                    severity=CheckSeverity.INFO,
                    current=f"{name} ({mem})",
                    message=f"检测到 NVIDIA GPU: {name}",
                    details={'memory': mem, 'utilization': util}
                )

        return CheckResult(
            check_id='gpu_detected', passed=False,
            severity=CheckSeverity.WARNING,
            current='none', expected='detected',
            message='未检测到独立 GPU，将使用 CPU 推理'
        )


@registry.register('gpu_detected', 'NVIDIA')
class JetsonGPUDetector(CheckStrategy):
    """Jetson GPU 检测——不依赖 nvidia-smi"""

    def run(self, adapter: BaseAdapter, ctx: CheckContext) -> CheckResult:
        # 直接使用 Jetson 适配器
        gpu_info = adapter.get_gpu_info()

        if gpu_info is None:
            return CheckResult(
                check_id='gpu_detected', passed=False,
                severity=CheckSeverity.WARNING,
                current='none', expected='detected',
                message='未检测到 Jetson GPU，可能驱动未正确安装'
            )

        return CheckResult(
            check_id='gpu_detected', passed=True,
            severity=CheckSeverity.INFO,
            current=f"{gpu_info.model} ({gpu_info.memory_total})",
            message=f"Jetson 内置 GPU: {gpu_info.model}",
            details={'source': gpu_info.source, 'status': gpu_info.status}
        )
```

### 4.6 平台抽象层（platform/）

隔离操作系统差异，提供安全统一的系统访问接口。

```python
# platform/base.py

class Platform(ABC):
    """平台抽象基类"""

    @abstractmethod
    def read_file(self, path: str) -> Optional[str]:
        """安全读取文件，无权限返回 None 而非崩溃"""

    @abstractmethod
    def run_command(self, cmd: List[str], timeout: int = 10) -> CommandResult:
        """执行命令，超时返回失败而非卡死"""

    @abstractmethod
    def list_dir(self, path: str) -> List[str]:
        """安全列出目录"""

    @abstractmethod
    def check_permission(self, path: str) -> bool:
        """检查是否有读权限"""


# platform/path_utils.py

def safe_exists(path: Path) -> bool:
    try:
        return path.exists()
    except PermissionError:
        return False

def safe_read_text(path: Path, default: str = '') -> str:
    try:
        return path.read_text()
    except (PermissionError, FileNotFoundError, UnicodeDecodeError, IsADirectoryError):
        return default

def safe_stat(path: Path) -> Optional[os.stat_result]:
    try:
        return path.stat()
    except (PermissionError, FileNotFoundError):
        return None
```

## 九、CHANGELOG（草稿）

```markdown
## [6.0.0] - 2026-XX-XX

### Breaking Changes
- requires-python >= 3.8 (previously implicit 3.10+)
- 目录结构重构：新增 adapters/ 和 platform/ 目录
- arm_diagnose.py 入口行为变化：先识别设备再执行检测

### Added
- **Device Fingerprint System**: 自动识别设备型号/厂商/架构/能力
- **Adapter Layer (adapters/)**: Jetson / RPi / Rockchip / QNAP / Synology / Generic
- **Strategy Pattern**: 检测策略按设备类型路由
- **Platform Abstraction (platform/)**: 统一安全的系统访问接口
- **Jetson GPU Detection**: 支持 tegrastats / sysfs，不依赖 nvidia-smi
- **Jetson CUDA Detection**: 探测 /usr/local/cuda* 安装路径
- **Raspberry Pi Detection**: 支持 vcgencmd / sysfs
- **Graceful Degradation**: 无权限时返回 INFO 而非崩溃
- **--fast mode**: 跳过慢速检测，加速诊断
- **Progress Indicator**: 检测过程显示进度
- **Adapter Extension API**: 支持第三方自定义适配器
- **CUDA Capabilities Probe**: 探测所有可用 CUDA 工具和库
- **Python 3.8 Support**: 全面兼容 Python 3.8（ARM 设备主流版本）

### Fixed
- GPU detection now correctly identifies Jetson devices
- CUDA detection searches install paths, not just PATH
- Network check timeouts reduced (10s → 3-5s)
- PermissionError no longer crashes diagnosis
- Module import path pollution no longer causes conflicts
- quick_diagnose now returns correct scores (not 0/0)
- All checks respect device-specific capabilities
```

## 十、风险与预案

| 风险 | 概率 | 影响 | 预案 |
|------|------|------|------|
| Jetson GPU 识别仍不准确 | 中 | 高 | 提供手动覆盖参数 `--gpu-type` |
| 真机测试设备不足 | 高 | 中 | 购买 Jetson Orin / Orange Pi 5 |
| 策略模式迁移破坏现有功能 | 中 | 高 | 完整保留 generic 策略兜底，渐进迁移 |
| Python 3.8 语法检查遗漏 | 中 | 高 | CI 强制包含 3.8 测试 |
| 第三方适配器接口设计不合理 | 低 | 中 | 预留接口演进空间，v6.0 不锁定 |
| 发布延期 | 高 | 中 | 按优先级分批交付（先适配层，后策略） |
