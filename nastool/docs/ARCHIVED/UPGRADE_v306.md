## P0 任务 — 核心体验优化（4小时）

### P0.1 智能摘要输出（1.5小时）

**问题**：诊断输出几十行，用户看花眼

**解决**：
```
之前：
  ✅ CPU: OK
  ✅ Memory: OK
  ✅ Disk: OK
  ...（20行输出）

之后：
  🎉 设备健康！所有检查通过
  
  💡 建议：磁盘剩余 35%，建议清理旧文件
```

**实现**：
- 顶部显示「一句话结论」
- 只显示「需要关注」的问题
- 底部显示「下一步建议」

### P0.2 操作建议系统（1.5小时）

**问题**：发现问题后，用户不知道该干嘛

**解决**：
```
❌ 发现 3 个问题：
  1. 磁盘空间不足（剩余 15%）
     → 建议：运行 python arm_diagnose.py --fix
     → 或手动清理：rm -rf /tmp/*
  
  2. 内存使用率 92%
     → 建议：重启服务或清理缓存
  
  3. AI 算力未检测到
     → 建议：安装 CUDA 驱动
```

**实现**：
- 每个问题配一条「可执行建议」
- 优先级排序（严重问题在前）
- 一键执行按钮（Web Dashboard）

### P0.3 快捷命令别名（1小时）

**问题**：命令太长，用户记不住

**解决**：
```bash
# 之前
python arm_diagnose.py --fix --auto

# 之后（提供快捷脚本）
./check.sh          # 快速诊断
./fix.sh            # 自动修复
./report.sh         # 生成报告
./monitor.sh        # 启动监控
```

**实现**：
- 创建 4 个快捷脚本
- Windows 批处理 + Linux Shell 双版本
- 零参数，一键执行

## P1 任务 — 场景化体验（3小时）

### P1.1 预设场景模式（1.5小时）

**问题**：用户不知道用哪个参数组合

**解决**：
```bash
# 场景模式
python arm_diagnose.py --scene quick      # 快速检查（30秒）
python arm_diagnose.py --scene daily      # 日常巡检（2分钟）
python arm_diagnose.py --scene full       # 深度诊断（5分钟）
python arm_diagnose.py --scene ai         # AI 算力专项
python arm_diagnose.py --scene storage    # 存储专项
```

**实现**：
- 预定义 5 个场景
- 自动选择检查项
- 自动设置超时

### P1.2 友好错误提示（1.5小时）

**问题**：错误信息技术化，普通用户看不懂

**解决**：
```
之前：
  ImportError: No module named 'yaml'

之后：
  ❌ 缺少依赖：PyYAML
  
  📦 安装方法：
     pip install pyyaml
  
  或一键安装所有依赖：
     pip install -r requirements.txt
```

**实现**：
- 错误码 → 友好提示映射
- 提供具体解决方案
- 多语言支持（中/英）

## P2 任务 — 便捷性增强（2小时）

### P2.1 配置向导（1小时）

**问题**：用户不知道怎么配置

**解决**：
```bash
python arm_diagnose.py --setup

# 交互式配置
? NAS 后端地址: (http://192.168.1.100:8000)
? 检查间隔: (5分钟)
? 告警阈值 - CPU: (80%)
? 告警阈值 - 内存: (90%)
? 告警阈值 - 磁盘: (85%)

✅ 配置已保存到 config.yaml
```

### P2.2 一键诊断脚本（1小时）

**问题**：新用户不知道从哪开始

**解决**：
```bash
# 创建 start.sh / start.bat
#!/bin/bash
echo "🚀 nastool 快速诊断向导"
echo ""
echo "请选择操作："
echo "  1. 快速检查（推荐新手）"
echo "  2. 完整诊断"
echo "  3. 修复问题"
echo "  4. 生成报告"
echo "  5. 启动监控"
echo ""
read -p "请输入选项 [1-5]: " choice

case $choice in
  1) python arm_diagnose.py ;;
  2) python arm_diagnose.py --full ;;
  3) python arm_diagnose.py --fix ;;
  4) python arm_diagnose.py --output report.html --format html ;;
  5) python arm_diagnose.py --monitor ;;
esac
```
